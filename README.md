## Selected Projects

### [Cogic](https://github.com/ppsssj/Cogic)
TypeScript·JavaScript 코드 구조와 관계를 그래프로 분석·탐색하는 VS Code 확장 프로그램입니다.

- AST 기반 코드 분석과 호출·참조·데이터 흐름 관계 탐색
- Trace Mode, 분석 캐시 및 소스 코드 이동 기능
- VS Code Marketplace 배포

`TypeScript` `React` `VS Code Extension API` `AST`

[Repository](https://github.com/ppsssj/Cogic) · [Marketplace](https://marketplace.visualstudio.com/items?itemName=ppsssj.cogic)

### [Peephole](https://github.com/The-peephole/peephole)
GitHub 저장소를 로컬에 직접 clone하지 않고 미리보기·분석할 수 있도록 개발 중인 도구입니다.

- Chrome 확장 프로그램과 서버 실행 환경을 연결하는 저장소 미리보기
- 격리 실행 환경과 프리뷰 수명 주기 관리
- 외부 API 오류 처리 및 운영 검증을 통한 안정성 개선

[Repository](https://github.com/The-peephole/peephole)

### [GraphMind](https://github.com/ppsssj/GraphMind-monorepo)
수식과 데이터를 2D·3D 그래프로 시각화하고 편집·저장하는 수학 워크스페이스입니다.

- 수식·그래프 연동과 3D 곡선·곡면 시각화
- Studio 편집 환경 및 Vault 저장 기능
- AI Panel을 통한 분석·조작 지원

`React` `React Three Fiber` `Math.js` `Spring Boot`

[Repository](https://github.com/ppsssj/GraphMind-monorepo)
